# GAB classic views

Two earlier designs of GAB, the Voice Autopilot benchmark for SikhiToTheMax (STTM) Desktop, kept as they were in October 2026:
a click-through view (overview per category, then a page per recording with its audio) and a card view (Actual / version bars).
They use that week's scoring (by Shabad, model-aligned pangti timings), which is more lenient than the current benchmark at
https://huggingface.co/spaces/khalisfoundation/GAB. Only recordings that are public on YouTube are included; the audio is
cut from those public source recordings. The second-by-second view follows Karanbir Singh's
[Live Captioning for Gurbani Kirtan benchmark](https://github.com/karanbirsingh/live-gurbani-captioning-benchmark-v1), with thanks.
