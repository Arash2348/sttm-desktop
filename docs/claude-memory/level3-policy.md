User approved 2026-09-25: Level 3 smagam data (AKJ etc., widely captioned) is collected and labelled as its own set.
Level 2 (regular gurdwara hall diwans — Renton, Harmandir Sahib, Fremont, Yuba City) stays the pass/fail benchmark.

**Why:** Level 2 caption sources are scarce (scouts 2026-09-25 found no captions at Brampton, Richmond Hill, Stockton,
Southall, Gravesend, Smethwick); Level 3 is plentiful, but the user doesn't want it to make Level 2 worse.

**How to apply:** keep L3 rows in separate files/tabs; never tune thresholds or gates on L3; report L2 and L3 metrics
separately; L3 may be used as extra training/exposure data. Related: [[verified-data-home]]
