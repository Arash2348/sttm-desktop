Buckets per second of singing/reading: ON (text match, any Shabad/Bani label), CATCHING UP (< 1 s
into a new pangti, previous still shown), BEHIND/AHEAD (1 off > 1 s), LOST (2+ off, same
Gurbani), WRONG PAGE (other Gurbani), BLANK. The user: "the 2 good are what we want to maximise."

**How to apply:** every report and every tuning target uses ON + CATCHING UP as the headline,
human-keyed sets first ([[human-labels-first]]), with wrong-page s/h and catch-up lag beside it.
Old "exact line" / "within one line" numbers are retired from headlines. Scorer:
sttm-replay research/level2-dataset/tools/sangat-score.js (being built Oct 13). See
[[north-star-goals]], [[always-baseline-numbers]].
