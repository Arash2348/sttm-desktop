1. Kirtan of a Shabad: high accuracy and fast.
2. Paath of the main Banis, high accuracy and really fast: the 7 main = Japji, Jaap, Tav Prasad
   Savaiye, Chaupai, Anand Sahib (full 40 pauris), Rehras, Kirtan Sohila; plus common: Salok
   Bhagat Kabeer, Salok Bhagat Fareed, Salok Mahalla 9, Aarti, Asa di Vaar.
3. Kirtan of a Bani: the above sung like kirtan (Rehras, Aarti, Asa di Vaar, Kabeer/Fareed Saloks).
4. Switching Shabad within kirtan: accurate, correct, fast.
5. Akhand Paath: Guru Granth Sahib from beginning to end in order.

**How to apply:** status tables and gap analyses are organised by these five; test sets must
cover each (gaps as of Oct 13: no Japji/Jaap/Savaiye/Chaupai/Anand-40/Salok Kabeer/Fareed/M9
line-level truth; no sung-Rehras/Fareed set; Akhand only 3 YouTube Sehaj clips).
