The user (Oct 14 2026): the GAB Space "is really dense, we need to be way more lean and simple"; they mostly read the dataset card's short leaderboard, not the Space.

**Why:** dense pages with many columns, tags and sub-notes don't get read; the point is to see at a glance which version is best and whether each new version is better.

**How to apply:** default views show one releases table (oldest to newest, current marked) with traffic-light colours and ≤6 short columns, plus a separate "ideas being tested" table vs their own base; commit ids, clip counts, caveats and deep metrics go behind a Details toggle or fold. Same for reports to the user. See [[results-as-tables]], [[gab]].
