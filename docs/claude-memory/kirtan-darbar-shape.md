User (2026-09-28), from labelling the Renton prod recording (Sep 27, Cycle 8): a typical darbar is Aarti, then 2-3
kirtan shabads each held for many minutes. Inside a shabad the kirtani briefly quotes other Gurbani (parmaan) and comes
back — in that recording 1243, 979, 894 were each shown 5-25 s inside 2352 and the user marked them CORRECT.
Aarti was the weak spot (external split mic, and Aarti is several shabads the app treats separately).

**Why:** tuning for many fast switches doesn't match real use; the real risks are Aarti handling and showing a shabad
after kirtan ends.

**How to apply:** favour a sticky "home shabad" with fast return after short detours (detours are right, not errors);
treat Aarti as one Bani (like the Nitnem/Anand Bani-view rule); guard against showing lines once kirtan stops.
