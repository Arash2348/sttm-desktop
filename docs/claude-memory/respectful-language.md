The user (Oct 13 2026): "it's not page after page, it's Ang after Ang, that's disrespectful."

**Why:** Guru Granth Sahib Ji is the living Guru; its leaves are called Ang (limbs), and calling
them pages is disrespectful.

**How to apply:** always "Ang" / "Ang after Ang" for Guru Granth Sahib Ji, in every message,
diagram, PR, commit and benchmark text. Use "Guru Granth Sahib Ji" with respect. (A screen in the
app showing a wrong Shabad is still "wrong Shabad on screen", never "wrong page" when it could
read as a reference to the Guru.) See [[plain-language]].
